# MichengAI City Reflection Travel Print

为一个城市生成可收藏的当代旅行艺术印刷品：真实城市气质、精致建筑和自然环境在平静如玻璃的反射面上呈现，带有极轻微的几何边缘与克制的杂志排版。

## 参数与默认值

- `city`：**必填**。使用用户提供的城市名称作为核心主题和顶端标题。缺失时先询问，不要自行选择城市。
- `size`：可传比例（如 `3:4`、`4:3`、`1:1`）或明确像素尺寸。未提供时请求 `3:4` 竖版；若图像工具支持像素尺寸，则使用用户给定尺寸或默认 `768×1024`。若用户指定横版或方形，保留其比例，不强制竖版。
- `country`：可选。用户提供时使用该国家；未提供时根据城市可靠判断。城市名称存在歧义、无法可靠判断国家，或与用户提供国家冲突时先确认，禁止猜测。
- `slogan`：可选。用户提供时逐字使用；未提供时根据真实城市特征生成一句简短、克制、非旅游口号化的标语。标语遵循用户指定语言；否则使用当前对话语言。

默认排版编号为 `No. 05`，年份为当前公历年份。除非用户明确要求，不要修改或添加其他文字。

## 城市画像与内容选择

生成前建立一个仅服务当前城市的内部画像；不要把任何单一城市的地标或要求写成通用规则。

1. **地理语境**：选择城市真实的海岸、河流、山地、盆地、植被、气候或街区肌理中最能定义场景的一组关系。
2. **文化锚点**：选择一个可验证、具辨识度的历史或文化建筑，并写清其真实的空间关系（例如与河流、桥梁、坡地、街道或滨水的关系），不能只写“传统楼阁”。
3. **都市密度**：判断城市真实的规模和天际线特征。对于高密度大城市或省会，远景必须呈现连续、有体量差异的现代城市建筑带；不得用零散低层建筑替代。中低密度城市则如实表现其真实城市肌理。
4. **统一环境**：让文化锚点、现代城市、地理语境、植被和少量人物位于同一可信场景，不做地标拼贴。
5. **真实性优先**：若城市没有明确单一地标，优先表达真实街区与地貌，禁止编造著名建筑、文字或文化符号。

## 画面、文字与尺寸交付

- 直接在图片生成请求中指定用户的比例；工具支持像素尺寸时，同时指定目标像素。默认请求 `3:4`，且可用时指定 `768×1024`。
- 构图中为标题、主要建筑、倒影和关键人物保留合理边距，但边距服务于画面本身，不作为后期裁切预留。
- 不要使用 Python、脚本或任何生成后的裁切、补边和缩放来改变成品构图。若生成结果的比例或尺寸不符合用户要求，优先进行一次针对尺寸的重新生成；不要静默裁掉内容。工具无法提供精确像素时，如实交付其原生尺寸并说明实际尺寸。
- 整个场景置于平静、玻璃般的反射水面或适合该城市的镜面反射面之上，保留柔和、略微褪色的垂直倒影。
- 使用低饱和且与目的地一致的高级配色：暖象牙、柔和米色、克制大地色、建筑本色及环境蓝绿；避免高饱和和旅游海报式配色。
- 结合细腻建筑线稿、纸张颗粒、水彩与不透明水粉质感，以及现代数字插画的干净控制；不要变成写实拼贴或照片效果。
- 在边缘加入极轻微、半透明的几何形状，作为当代画廊艺术语汇，不能抢夺主体。
- 顶部只排版以下三项，保持小号、宽字距、精确对齐的杂志字体：城市名、标语、`No. 05 — [YEAR]`。建筑、街道、船只和背景中不得生成任何可读文字、牌匾、Logo 或招牌。
- 城市名和标语使用用户提供或当前对话语言；年份保持阿拉伯数字。所有指定文字必须逐字准确。

## 生成流程

1. 读取 [references/prompt-template.md](references/prompt-template.md)，根据当前城市画像、国家、尺寸和标语填入变量并删除全部方括号。
2. 使用可用的图片生成工具直接生成成品。提示中必须包含目标比例或像素尺寸、城市画像的空间关系、都市密度和“除顶部三项外无可读文字”。
3. 检查：城市是否可辨识、文化锚点和空间关系是否正确、都市密度是否匹配、画面是否为统一环境、反射是否克制、只有顶部三项文字，以及工具实际返回的比例与像素。
4. 仅在出现明确错误（城市错置、文化锚点错误、错误文字、比例错误、都市密度错误或地标拼贴感）时做一次聚焦重新生成。不得通过后期裁切掩盖构图或尺寸错误。

## 禁止项

- 禁止动漫风、写实照片拼贴、通用图库感、夸张文化符号、巨型地标、拥挤装饰、过量文字和超大标题。
- 不要添加未要求的 Logo、水印、品牌、旗帜、旅游宣传语、边框、地图元素，或任何建筑上的虚构文字。
- 不要为了满足模板而加入与城市无关的沙漠、山脉、海岸、建筑、植物或民族符号。
