# MichengAI Photo Felt Relief Travel Archive

**中文** · [English](./README.en.md) · [返回仓库首页](../README.md)

将每张参考照片一次性制作成一张独立的 `3:4` 竖版旅行材料档案：暖米白纸上依次放置同尺寸、同长宽比的完整原始照片与混合材料浅浮雕，再在底部加入英文打字机档案文字。横图使用等宽横向面板，`1:1` 方图使用两块居中的等大方形面板，竖图同样保持原始比例。

## 输入

| 参数 | 是否必填 | 规则 |
| --- | --- | --- |
| `reference_image` | 是 | 每张照片独立处理，并作为该海报的唯一视觉事实来源。 |
| `size` | 否 | 默认 `3:4` 竖版，保持上方约 46%、下方约 54%。 |
| `title` | 否 | 可提供英文标题；未提供时根据真实可见场景自动生成。 |
| `scene_subtitle` | 否 | 可提供英文场景副标题；不得编造地点。 |
| `description` | 否 | 可提供 1–2 句英文描述；未提供时只根据照片事实生成。 |
| `study_number` | 否 | 单张默认 `01`；多张按输入顺序递增。 |

## 特征

- 上方照片以等比缩放完整装裱，不裁切、不拉伸、不扩图，也不改变构图、色彩、光影和主要景物。
- 根据原图长宽比自动选择横图、方图或竖图版式；上下两个面板始终等宽、等高、同长宽比，英文档案文字统一放在材料画下方。
- `1:1` 输入对应两块居中的等大方形面板，不使用横向装裱框，也不把下方材料画扩展为横图。
- 下方是一整块带细微毛边和整体投影的矩形材料画，严格复现同一镜头的主体数量、位置、比例、朝向、透视与前中后景关系。
- 以层叠裁剪毛毡和针毡羊毛为主，根据画面少量搭配树皮、软木、旧木、麻布、纸浆、石膏或金属丝。
- 采用壁挂式低浅浮雕：最大起伏约 `5–12 mm`，毛毡以 `1–3 mm` 薄片叠层，突出针刺纹理、纤维、毛边、接缝与自然瑕疵。
- 使用暖米白纤维纸、低饱和来源色与哑光材料，形成博物馆旅行标本般的档案摄影质感。
- 自动生成英文标题、带 `STUDY NO.` 的场景行、1–2 句描述和斜杠分隔材料行；只使用克制的复古打字机排版。
- 明确排除针织、钩织、毛绒玩具、塑料模型、光滑 3D、水彩、卡通、界面、水印和无关文字。
- 每张完整海报在一次图片编辑调用中生成，不依赖脚本、网页或后期软件拼版。

## 使用

```text
使用 `michengai-photo-felt-relief-travel-archive` 将我上传的每张照片分别制作成一张 3:4 羊毛毡浅浮雕旅行档案海报。
```

```text
使用 `michengai-photo-felt-relief-travel-archive` 处理这张照片。上方完整保留原照，下方制作成等宽矩形材料画，档案文字放在材料画下方。
```
