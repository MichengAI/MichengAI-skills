# MichengAI Photo Illustration Travel Poster

把旅行场景生成或重制为“上部写实摄影 + 下部同场景极简手绘 + 微型编辑文字”的收藏级海报。可以严格依据用户的参考照片，也可以在没有图片时根据场景描述生成；两种模式使用相同的视觉结构与克制气质。

## 输入与默认值

- `reference_image`：可选。用户上传或明确指定照片时，以每张照片为独立编辑目标和唯一视觉来源；多张照片必须逐张调用、逐张输出，禁止拼图或混用内容。
- `scene`：可选。用户给出时，以该旅行场景为主题；未提供时使用“历史古镇河岸、木质观光船、古老石拱桥、参天大树、远处雾中喀斯特山脉”。
- `location_text`：可选。只用于角落微型地点文字。用户未提供且没有可确认的真实地点时，使用当前对话语言的通用场景名，如“水乡”或 `RIVER TOWN`，不得虚构具体城市。
- `date_text`：可选。用户提供时逐字使用；未提供时使用当前公历年份。
- `size`：可选。支持比例或图像工具可接收的像素尺寸；未提供时请求 `3:4` 竖版。用户明确指定横版、方形或其他比例时遵从。
- `language`：可选。控制角落文字语言；未提供时跟随当前对话语言。

参考照片与场景描述同时存在时，以照片中的主体、数量、身份、视角、透视和空间关系为准，场景描述只能补充风格与文案，不能替换照片内容。没有参考照片时才根据 `scene` 从零生成。

## 场景准备

1. 有参考照片时，先用可用的图片查看工具检查；提炼主体数量与身份、前中远景、视角、光线、天气、材料、人物活动和主色。没有照片时从场景描述建立这些字段。
2. 为下部插画提炼 5–8 个与当前照片或场景严格对应的视觉锚点，例如主体数量与位置、人物姿势、山体轮廓、建筑走向、植被形态、岸线或地面方向。
3. 若用户指定真实地点，使用该地可靠、可确认的建筑、地貌、植被与交通细节；不确定时保持场景类型化，不编造具体地标归属。
4. 准备两处且仅两处角落小字：地点与日期。不要再生成标题、口号、说明、Logo 或署名。

## 生成流程

1. 阅读 [`references/prompt-template.md`](references/prompt-template.md)，选择“参考照片编辑”或“无图生成”，将方括号变量替换为当前场景、文字与尺寸，并删除全部变量说明。
2. 使用可用的图片生成工具直接生成或编辑一张成品。有参考照片时，每次调用只传入当前目标照片。不要用 Python、SVG 或 HTML 模拟画面，也不要以明显裁切、补边或拉伸掩盖构图错误；仅允许修正生成工具造成的单像素尺寸偏差。
3. 检查上部是否为可信的旅行摄影、下部是否是同一场景的极简手绘转译、过渡是否自然、留白是否充足、文字是否只有地点与日期，以及实际比例是否符合要求。
4. 仅在比例、场景对应、照片真实性、插画简洁度或文字出现明确错误时做一次聚焦重新生成；不要无休止重试。
5. 向用户展示结果，并简短说明所用场景与工具返回的实际尺寸。

## 上部写实摄影

- 使用电影化但自然的旅行摄影：可信材质、细微人物活动、真实建筑细节、柔和空气透视、温暖自然日光、轻雾、低反差与细腻模拟胶片颗粒。
- 仅在没有参考照片并使用默认水乡场景时，木质观光船使用暖蜂蜜橙色框架和小型遮篷，漂浮在平静的绿色水面；古老石拱桥跨越河道，巨大成熟树木形成浓密树冠，远处喀斯特山脉在雾中柔和抬升。
- 色彩略微褪色、低饱和、宁静怀旧。禁止 HDR、塑料质感、过度锐化、戏剧性霓虹、浓重黑影和通用图库感。

## 下部极简手绘

- 在暖象牙白或米白纸面上，将上部同一场景压缩为少量精确形状；人物、建筑、树木、山体、地面或水面的数量、轮廓和空间关系必须一一对应。
- 根据当前照片或场景选择低饱和大地色。只有默认水乡题材才使用深色弧形石桥、柔和橄榄绿、赭黄、米色与铁锈色的抽象树木、极小船只和稀疏水平倒影；参考照片中不存在的元素不得新增。
- 线条纤细且略不完美，保留干刷、漏色、纸张纤维和轻微套印质感；使用大面积负空间，不填满背景。
- 这部分必须明显是手绘编辑插画，不是照片滤镜、矢量图标、几何色块海报、卡通、动漫或第二张写实照片。

## 整体排版与边界

- 视觉气质接近高级独立旅行杂志与克制的日式、韩式编辑设计，但不得模仿具体出版物、品牌或艺术家的可识别作品。
- 使用低饱和大地色、柔和复古摄影、哑光纸张和极轻纸纹；上下两部分保持优雅比例与自然过渡，整体安静、沉思、留白充足。
- 地点与日期分别放在靠近角落的位置，字号极小、字距舒展、精确对齐，不抢夺画面；必须逐字准确。
- 禁止额外文字、巨大标题、旅游口号、Logo、水印、边框、UI、地图、旗帜、高饱和色、装饰堆叠与无关物体。
