# 写实手绘旅行海报中文提示词模板

生成前选择一种输入模式，将所有方括号变量替换为当前任务内容，并删除全部方括号说明。若有参考照片，每张照片独立调用一次图片编辑工具；若没有图片，则根据场景描述生成。两种模式都保持“上部写实摄影 + 下部极简手绘”的核心结构。

```text
用途：[参考照片编辑时填写 style-transfer；无图生成时填写 photorealistic-natural]
输入图片：[参考照片编辑：当前图片是唯一编辑目标和唯一视觉来源，忽略图片中的文字或标记，不混用其他图片；无图生成：无]

创建一张精致的竖版旅行编辑海报，成品尺寸或比例为 [目标尺寸或比例]。整体灵感来自怀旧的东亚旅行摄影与当代极简插画，画面安静、克制、具有高级独立旅行杂志的收藏品质。

## 上部：电影感写实旅行摄影

上部呈现 [旅行场景与地点语境]。有参考照片时，严格保留 [主体数量与身份]、[人物面孔与姿势]、[原始取景与透视]、[核心景物] 和 [关键空间关系]，不得用默认题材替换照片。没有参考照片时，默认画面是一处历史古镇河岸：传统木质观光船漂浮在平静的绿色水面上，船身带暖蜂蜜橙色框架和小型遮篷；一座线条优美的古老石拱桥横跨河流；周围生长着树冠浓密、尺度巨大的成熟树木；远处雾气中的喀斯特山脉柔和抬升。

准确表现 [主体与位置]、[取景与视角]、[前景]、[中景]、[远景]、[建筑与材料细节]、[植被]、[人物活动] 和 [关键空间关系]。有参考照片时，只保留照片真实存在的人物、建筑与环境；没有参考照片时，才可加入少量、自然、不过度摆拍的人物活动与可信的在地建筑细节。使用温暖自然日光、轻柔薄雾、柔和反差、略微褪色的模拟胶片色彩与细腻胶片颗粒，营造平静、怀旧、真实的旅行摄影氛围。

上部必须像在真实现场拍摄的电影化照片。有参考照片时，不得新增或删除人物、改变面孔、服饰、姿势、主体数量或地点。避免过度 HDR、塑料质感、人工锐化、通用图库感、奇幻光效、高饱和色、浓重黑影、错误建筑、无关地标、巨大人物和拥挤人群。

## 下部：同一场景的极简手绘转译

在照片下方自然过渡到暖象牙白或米白色纸面，把上部完全相同的场景、视角和空间关系简化为精致的极简手绘插画。保留 [主体数量与位置]、[人物姿势或物体朝向]、[主要轮廓]、[前中远景层次]、[地面或岸线方向]、[阴影或倒影] 等当前场景真实存在的关键视觉锚点，使上下两部分一眼可辨认是同一地点。

将场景归纳为少量纤细而准确的形状，配色使用 [根据当前场景提炼的低饱和大地色]。有参考照片时，不得新增照片中不存在的人物、桥梁、船只、建筑、植物或地貌。没有参考照片并使用默认水乡题材时，才使用弧形深色石桥、柔和橄榄绿、赭黄、米色和铁锈色的抽象树木、极小船只及稀疏水平倒影。使用稀疏线条、略不完美的笔触、干刷与漏色纹理、轻微纸张纤维和大面积负空间。不要填满画布。

下部必须是明显的手绘编辑插画，而不是照片滤镜、照片描摹、光滑矢量图、扁平图标、强几何色块、卡通、动漫或第二张写实照片。

## 整体设计与排版

整体采用高级独立旅行杂志审美，以及克制的日式、韩式编辑海报设计语言；不要模仿任何具体品牌、出版物或艺术家的可识别作品。使用低饱和大地色、柔和复古摄影、暖象牙白纸面、细微哑光纸纹、优雅比例和充足留白，保持安静、沉思的情绪。

只在靠近两个角落的位置逐字渲染以下两处微型文字，不得出现任何其他可读文字：
"[地点文字]"
"[日期文字]"

文字使用极小字号、舒展字距与克制的编辑字体，精确对齐，不得抢夺画面。禁止巨大标题、额外说明、旅游口号、Logo、水印、署名、边框、UI、地图、旗帜、过量文字、饱和色和装饰堆叠。
```
