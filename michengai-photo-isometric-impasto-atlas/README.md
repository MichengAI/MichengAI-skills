# MichengAI Photo Isometric Impasto Atlas

**中文** · [English](./README.en.md) · [返回仓库首页](../README.md)

将每张参考照片分别制作成一张 `3:4` 竖版场景图鉴：上半部保留可信的现场摄影，下半部用等距/轴测式空间重建同源主体与环境，并让整座微型场景坐落在取色自原图的不规则厚涂颜料地形上。画面沿水平中线严格对半，不进行多图拼接。

## 输入

| 参数 | 是否必填 | 说明 |
| --- | --- | --- |
| `reference_image` | 是 | 每张照片独立处理，并作为该成品唯一的视觉事实来源。 |
| `size` | 否 | 默认 `3:4` 竖版；其他画幅仍保持上下各 50%。 |
| `title` | 否 | 可用可靠地点、主体或叙事命名；无法确认地点时不猜测。 |
| `caption` | 否 | 一行具体观察，可省略。 |
| `number` | 否 | 可使用 `01`、`001` 等图鉴编号。 |

## 视觉特征

- 上区保持主体结构、镜头透视、自然材质、光影方向和现场色彩，只做克制的出版摄影调色。
- 下区从上方斜看，以稳定的平行关系和前中后层建立轴测微型空间，而不是正面插画、孤立图标或夸张广角模型。
- 主体与道路、水面、庭院、植被、山体或人物的关键关系会被保留，次要远景则按可读性归纳。
- 场景底部不是规则托盘，而是由原图主色构成的不规则颜料地形，带可见刮刀推抹、叠色与隆起边缘。
- 模型细节与油彩物质感并存，避免塑料 CG、树脂摆件、积木、黏土玩具和普通油画滤镜。
- 标题、短句、地点和编号只在下区留白中克制出现；地点不可靠时省略。
- 多张照片逐张编辑、逐张展示，一图一稿。

## 使用

```text
使用 `michengai-photo-isometric-impasto-atlas` 分别处理我上传的每张照片，每张单独输出一张 3:4 轴测厚涂场景图鉴。
```

```text
使用 `michengai-photo-isometric-impasto-atlas` 处理这张建筑照片。保留庭院与水面的空间关系；标题：水岸回声；编号：01。
```
