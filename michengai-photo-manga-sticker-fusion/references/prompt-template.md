# 真人摄影 × 黑白漫画贴纸融合中文提示词模板

每张照片独立使用一次。先根据参考照片选择“单人转绘”“群体转绘”或“角色置入”，填写方括号变量并删除其余两种模式的整段文字。不要把模板说明渲染进图片。

```text
用途：参考图精确编辑
编辑模式：[单人转绘 / 群体转绘 / 角色置入]
输入图片：只使用当前上传的这一张照片作为编辑目标和背景依据，不混用其他图片。

请以输入照片作为精确背景参考。完整保留原始真实环境、建筑、地标、透视、镜头畸变、相机位置、取景边界、光线、色彩、材质、阴影和整体构图。背景必须继续呈现清晰、细节丰富的真实摄影，不得重建为近似场景，不得动漫化、插画化或套用漫画滤镜。

## 目标人物与人数

[单人转绘：只把照片中的指定人物“[人物位置与身份描述]”转化为黑白手绘漫画贴纸。严格保留其原始站位、姿态、朝向、身形比例、头发轮廓，以及 [宽松 T 恤 / 牛仔裤 / 球衣号码 / 运动鞋 / 肩背包 / 配饰等实际可见细节]。不要改变其他人物。]

[群体转绘：照片中共有 [目标人数] 名共同构成主体的清晰人物。把以下人物全部、同时转化为黑白手绘漫画贴纸：
1. [人物 1：位置、年龄观感、服装、姿态与配饰]
2. [人物 2：位置、年龄观感、服装、姿态与配饰]
3. [继续逐人列出，数量必须与目标人数完全一致]

严格保持这组人物的总人数、逐人身份特征、原始站位、相对身高、身体比例、朝向、视线、手势、互动、人物间距离和前后遮挡。不得只转绘其中一人，不得遗漏、增加、删除、复制、合并、交换或移动任何人物。每个人的脸、头发、皮肤、服装、鞋和随身配件都必须完整转为同一套纯黑白线稿；不能出现脸部已插画化但身体仍保留彩色照片纹理，也不能让某个人仍保持真人摄影。画面中的 [非目标背景路人描述；若没有则写“没有”] 保持真实摄影，不参与转绘。]

[角色置入：在照片的 [前景或中景位置] 自然加入一名完整的黑白手绘漫画女孩。她采用 [站立 / 行走 / 回望等姿态]，穿着与 [地点与活动] 相符的现代休闲街头服装：[服装、鞋、包和配饰]。人物尺寸为 [相对画面或关键结构的明确比例]，放在 [偏左 / 偏右 / 其他避开核心结构的位置]；与 [栏杆 / 墙面 / 台阶 / 门框] 相邻时采用 [明确的扶栏 / 倚墙 / 踏阶动作]。不要删除或替换现场已有的人。]

## 人物画风

- 使用干净的黑色墨线，人物内部为白色或极浅灰，只保留极少必要阴影；人物本体不得出现任何彩色。
- 气质为可爱、时髦、自然的韩系街拍与日系漫画融合：比例修长而真实，五官简洁，眼神有表现力，避免 Q 版大头与夸张身体。
- 使用流畅的深色头发线条和少量黑色块面；线条清楚，但保留轻微不规则的手绘速写感。
- 每名目标人物的可见外缘必须形成连续醒目的黑色轮廓，并带一圈窄而均匀的白色刀模留边，像手工剪下后放入真实照片的漫画贴纸。人物互相遮挡的区域保留原始前后关系，不要用一整块白边把群体粘成无法区分的人形，也不要补画原图中不可见的身体部分。
- 不要机械矢量线、霓虹描边、彩色填充、厚重灰阶、密集交叉排线、3D 塑料质感或普通卡通渲染。

## 真实空间融合

所有目标人物的尺寸、站位和身体透视必须匹配照片中的广角透视、地平线、消失点、台阶、地面、床面、栏杆与建筑尺度。保持每个人在原图中的裁切状态：原本完整则完整，原本被遮挡或超出画面则不要凭空补全。每个可见脚底必须准确接触其对应的 [具体地面、床面或第几级台阶]，不得悬浮、穿地或落在错误平面。

按照照片原有的 [光线方向] 为每名目标人物保留或添加克制、真实的接触阴影和落影；阴影可继承环境颜色，但人物本体始终保持黑白。正确处理人物之间及人物与环境之间的遮挡：[人物交叠 / 栏杆 / 台阶边缘 / 墙角 / 前景物体] 应按照原图空间关系位于前方或后方，不得穿模。

先逐层写出完整深度顺序：[相机 / 室内前景] → [人物] → [栏杆、门框或其他结构] → [远景]。背景结构保真高于人物居中或视觉突出：原图中的 [横杆、栏柱、门框、台阶边缘等连续结构] 必须保持原来的数量、间距、位置、形状和连续性。只允许人物精确轮廓实际覆盖的少量像素被自然遮挡；人物轮廓之外的结构必须完整可见。禁止为了避免穿模而删除、缩短、打断、移动或重建大段背景结构。若人物会遮住过多结构，立即缩小人物、移到画面侧边，或改成手部明确接触结构的姿势。

## 必须保留的背景锚点

准确保留 [地标或建筑 1]、[地标或建筑 2]、[台阶 / 看台 / 栏杆]、[树木与天空]、[广告牌或环境文字的位置]、[原始主色]、[关键阴影] 和 [其他可识别周边]。保持原图宽高比与宽角构图，不新增边框、标题、Logo、水印、漫画速度线或无关物体。

最终效果应是：电影感旅行摄影 + 韩系街头摄影 + 黑白漫画墨线 + 手帐贴纸质感。彩色真实环境与单色人物形成强烈反差，但透视、光线、遮挡和接地必须无缝可信。只有人物是插画，除此之外的一切都保持真实摄影。

禁止：整个画面卡通化、背景重绘、地点变形、建筑简化、整体描边、改变画幅、只转绘群体中的部分人物、人物半照片半线稿、人物彩色化、人数错误、人物遗漏、人物复制、人物合并、身份交换、擅自移动人物、脚底悬空、错误平面接触、错误阴影、遮挡穿模、栏杆或连续结构被大面积抹除、结构出现缺口或断裂、多余肢体、伪文字、额外角色、无关道具、Logo、水印和低清模糊。
```

## 填写提示

- `单人转绘` 只在画面只有一名清晰主角，或用户明确指定某一人时使用。
- `群体转绘` 是多人合影或多人共同构成叙事主体时的默认模式；应先逐人数清并编号，再生成提示词。用户没有指定单人时，不要擅自只挑最显眼的一位。
- `角色置入` 只在照片没有目标人物，或用户明确说“加入一个角色”时使用。
- 远处路人、观众和偶然入镜者默认不纳入群体；用户明确说“所有人”时才全部转绘。
- 角色置入靠近栏杆、门框或台阶时，先保护结构连续性；人物宁可更小、偏侧，也不要居中遮住或破坏大段结构。
- 不要同时保留多种模式文字；删除不适用的整段。
- 球衣号码、服装印花和配饰只能根据照片中可辨认内容或用户明确说明填写；看不清时宁可省略，不要猜。
