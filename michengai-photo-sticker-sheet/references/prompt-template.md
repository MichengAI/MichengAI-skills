## 执行优先级

严格按照以下顺序执行：

1. 区域边界和非重叠版式正确；
2. 参考照片内容准确；
3. 贴纸元素确实来自原图；
4. 纸张、印刷和插画质感。

任何装饰效果都不得破坏版式、跨越区域或遮挡其他内容。

## 画布与三区网格

生成 [目标比例，默认 4:5] 竖版成品。使用温润的暖象牙白厚卡纸作为底板，四周保留约画布宽度 4% 的安全边距。

### A 区：上方写实主图

- 位置约为画布 `x=4%–96%`、`y=4%–56%`。
- 放置一张完整、干净的矩形或轻微圆角矩形照片面板。

- 只允许为适配面板进行轻微自然裁切；不得改变主体关系。
- 主图和投影必须完整留在 A 区内，不得伸入下方区域。

### B 区：左下手绘明信片

- 位置约为画布 `x=4%–48%`、`y=59%–96%`。
- 放置一张由同一场景转化而来的复古水彩、石版画或旅行明信片。
- 明信片必须保持完整矩形；四条边和四个角必须全部清晰可见。
- 明信片内部只表现同一场景，不放置独立贴纸。
- 任何元素都不得压住、遮挡、穿过或突出其边框。

### C 区：右下贴纸陈列

- 位置约为画布 `x=52%–96%`、`y=59%–96%`。
- B 区与 C 区之间保留至少画布宽度 4% 的完全空白沟槽。
- 放置 4–6 枚来源于参考照片的独立模切贴纸，优先使用疏朗的两列网格。
- 每枚贴纸的完整主体、暖白色刀模边和柔和投影都必须位于 C 区内部。
- 所有贴纸与 C 区边缘保持至少画布宽度 2% 的安全距离。
- 贴纸之间不得接触或重叠；不得进入 A 区或 B 区；不得跨越中间空白沟槽；不得被画布或卡纸边缘裁切。

如果 C 区空间不足，依次采用以下策略：减少贴纸数量；缩小贴纸尺寸；选择轮廓更紧凑的原图元素。绝不能通过重叠、越界、遮挡、裁切、倾斜、拥挤或跨区来容纳更多贴纸。

## 贴纸外观与整体风格

每枚贴纸只表现一个完整、清晰、可识别的主体或元素，使用自然模切轮廓、均匀暖白边缘、轻微纸张厚度和克制的柔和投影。不要重复相同元素，不要把贴纸做成生硬的矩形照片截图。

整体风格为高级博物馆商店纪念品、复古自然观察卡、收藏级贴纸套装和克制的编辑网格。上方保持真实摄影；左下使用细腻水彩或石版画转译；右下贴纸保持同一配色与材质语言。加入细小纸纤维、轻微印刷颗粒、哑光表面和统一投影，但保持排版规整、疏朗。

禁止自由拼贴、剪贴簿式重叠、跨区层叠、贴纸破框、随意旋转、强烈污渍、塑料 3D、卡通化和杂乱装饰。
