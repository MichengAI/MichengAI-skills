# MichengAI White-Space Memory Sketch

把参考照片重新组织成一页“纸上记忆标本”：依靠少量记忆锚点认出原场景，而不是依靠对山石、草叶、皮肤、木纹等摄影细节的逐项复刻。成品必须是一张重新构形、重新落笔的插画，不是照片滤镜，也不是把原图缩小后贴在白底上。

## 输入与边界

- 必须以用户上传或明确指定的照片为视觉依据。缺少目标图片时，请用户重新上传，不要凭空补造具体场景。
- 先检查照片，再确定主体、空间和情绪。默认只保留 2–4 个锚点：一个主体身份/姿态、一个关键空间关系，再加 0–2 个独特物件、轮廓或色彩。锚点之外的细节应合并、概括或删除。
- 用户指定比例、文案、语言、色彩或留白方向时优先遵循；未指定时使用 3:4 竖版。
- 多张照片默认逐张独立处理，每张生成一张成品，不把不同照片拼成一页。
- 这是风格重绘，不承担面部精修、像素级旧照修复、商品广告排版、密集拼贴或信息图任务。

## 生成流程

1. 用可用的图片查看工具检查目标照片，提炼“主体 + 场所 + 动作/关系 + 光线 + 情绪 + 主色/强调色”六类信息。
2. 从中选出 2–4 个不可丢失的记忆锚点，并挑选 1–3 个适合轻微越出主画域的轮廓锚点。先决定要删除什么：重复山石、草叶、墙面颗粒、湖面碎光、远处小物等非锚点摄影信息不进入重绘。
3. 阅读 [references/prompt-template.md](references/prompt-template.md)，按照片的主体方向、空间关系和情绪选择画页结构，填写变量并删除不适用段落。
4. 使用图片编辑/生成工具直接编辑参考照片。不要用滤镜、抠图贴白底、SVG、HTML 或本地绘图脚本冒充重绘。
5. 检查主体是否仍可辨认、主画域是否避免僵硬矩形、实际着色面积与整组外包围是否同时受控、越界元素是否克制、留白是否形成主要视觉体量、文字配色是否来自照片且清晰准确。特别检查插画内部：即使遮住白纸、刷边和题字，它也必须仍然明显是线条、色块与水洗重新画成的，而不是一块带手绘纹理的照片。出现明显偏差时只做一次针对性修正；不要无休止重试。
6. 展示成品，并简短说明保留了哪些记忆锚点。除非用户要求，不要只交付提示词。

## 画面结构

- **纸面形成舞台**：使用干净的冷白、自然白或极浅暖白纸张；画页四周保留至少约 10–15% 的安静纸边，顶部通常保留约 28–35% 的连续留白。插画、越界线条和文字都不能触碰页面边缘。
- **双重尺度约束**：实际有色笔触与明显线条约占整页 25–32%；同时限制插画整体外包围框（包含越界锚点）：横向景观约不超过页面 72% 宽 × 46% 高，纵向主体约不超过 48% 宽 × 62% 高，一角式静物约不超过 60% 宽 × 52% 高。这些比例只控制视觉尺度，不得画成可见矩形边框。
- **版式跟随照片**：根据原图的运动方向、地平线、人物视线和视觉重心，在中下段偏左、偏右、斜向展开、卷轴式纵向或撕纸拼接中择一；禁止每张都套用居中的圆角矩形。
- **画域不封死**：主画域可以是水墨晕染、横向刷痕、宣纸撕边、散点彩铅或不规则拼贴，不要形成四边等距的封闭相框。
- **允许克制越界**：选择 1–3 个最有识别度的轮廓，例如塔尖、树枝、人物、绳索、水流、倒影、花簇、屋檐或招牌，让其自然越出主画域约自身尺度的 5–8%。越界应只发生在一到两个方向，并计入整体外包围限制；不能借长线、山脊、窗框或刷痕把视觉范围拉到页边。
- **保留关系，不锁死轮廓**：保持人物数量、主体朝向、相对位置、支撑/接触关系和主要光线方向；允许压平透视、合并形体、调整局部比例和改写轮廓，只要 2–4 个记忆锚点仍足以识别原场景。
- **边缘有收有放**：大部分边缘通过铅笔线、水彩晕染、宣纸纤维或干刷痕迹轻轻收住；关键越界锚点保持完整轮廓，形成疏密、虚实和开合变化。

## 手绘语言

- 以当代中式纸本为主：从石墨/毛笔线、淡墨、水彩淡彩、彩铅、木版套色感、宣纸撕边和细颗粒印刷感中选择 2–3 种组合；不要把所有效果机械叠加。
- 先把照片拆成少量大形：主体轮廓、地面/水面、远景、光影和一处强调色。山石归并成坡面与皴擦，树林归并成树冠团块，草地归并成色带，建筑归并成主要立面；不要逐颗、逐叶、逐砖复刻。
- 笔触应有手工温度和轻微不完美。锚点需要清楚，但轮廓不能像照片边缘检测，表面不能保留镜头锐度、摄影噪点、HDR 微反差或连续写实材质。
- 以原照片颜色为基础，将其转译为墨色、赭石、朱砂、石青、石绿、藤黄或花青等相近纸本色阶；不为追求“中式”而强行改变照片的核心色彩。
- 宣纸撕边、藏书签、朱印小点、旧票据或纸胶带只在题材适合时少量使用；它们是构图节点，不是装饰清单。
- 中式气质来自计白当黑、疏密、虚实、散点与书写关系。禁止凭空加入灯笼、祥云、宫殿、篆刻大印或其他与照片无关的符号。
- 禁止照片滤镜感、满版铺色、扁平矢量图、厚重油画、塑料 3D、泛黄仿古纸、商业大标题和装饰堆叠。

## 页边注规则

- 文字是画页结构的一部分，但不是海报标题。除非用户明确要求“不要文字”，默认必须生成一条中文手写短句和一个更小的英文档案标签/日期。
- 中文短句通常使用 6–14 个汉字，放在插画下方、右侧或上方留白中；英文标签使用 2–4 个大写单词并可附 `MM/DD`，放在中文附近或插画相邻留白中。两组文字不能重叠插画主体。
- 题字应靠近插画形成一个紧凑视觉组，与主画域保持约页面短边 3–8% 的呼吸距离；不要把中文、英文分别推到页面两端，也不要让题字扩大整页视觉外包围。
- 文字颜色不得固定。先从照片提炼“墨色/深色文字色 + 强调色”：中文优先使用能代表画面气质且与纸面有足够对比的墨黑、深靛、赭褐、松柏绿或深紫；英文/日期使用画面中的次级强调色，如朱砂、石青、石绿、藤黄、樱粉或茶褐。
- 暖色照片可使用赭墨中文配朱砂/藤黄英文；冷色照片可使用深靛/墨灰中文配石青/石绿英文；接近黑白的照片使用墨色中文与一点朱砂。颜色选择必须服务于画面，而不是套用固定“深灰 + 蓝灰”。
- 用户给出原文时逐字保留；自行生成时只描述照片真实存在的细节或情绪，不编造地点、日期和故事。
- 在生成提示中把每段文字分别引用一次，并要求逐字准确。若文字出现乱码、重复或抢占画面，优先删除次要文字，而不是放大字号。
- 禁止 Logo、水印、签名、长段落、重复短句和任何未要求的文案。

## 验收标准

- 缩略图下首先读到大片干净纸面，其次看到具有疏密变化的开放画域，而不是居中模板框。
- 同时检查两个尺度：着色与明显线条约占 25–32%，插画整体外包围符合横向、纵向或一角式上限；稀疏笔触不能成为把大画幅伪装成低占比的手段。
- 放大后能辨认参考照片的主体、动作或空间关系，而不是泛化成任意同类场景。
- 小画是重新构形后绘制的，不含矩形照片残片、明显抠图边或滤镜后的摄影纹理；非锚点细节密度应显著低于原照，至少有一个、最多三个轮廓锚点自然越出主画域。
- **内部重绘测试**：忽略白纸、刷边与文字后，插画内部仍应由可见线条、有限色块、透明水洗和纸面留白构成。若山石、草叶、皮肤、木纹或水面仍像摄影素材，只是叠了颗粒与笔刷，判定失败。
- 留白不是空洞背景：小画位置、朝向和页边注共同形成稳定而克制的页面平衡。
- 默认同时出现一条中文手写短句和一个小型英文/日期标签；颜色与照片主色/强调色有明确关系，少、细、准确，没有乱码、重复、额外标志或虚构地点。
- 整体应有当代中式纸本气质，但不靠无关传统符号证明“中式”。
