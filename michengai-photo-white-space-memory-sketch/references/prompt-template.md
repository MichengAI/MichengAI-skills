# 白纸记忆小画中文提示词模板

先根据目标照片完成“记忆锚点卡”，再填写生成提示。方括号内容是变量说明，提交给图片工具前必须替换或删除。每张照片单独调用一次图片编辑工具。

## 记忆锚点卡

```text
核心主体：[人物 / 动物 / 物件 / 建筑 / 场景]
主体状态：[姿态、动作、朝向、表情或物件形态]
空间关系：[主体与地面、家具、窗户、道路、远景等的相对位置]
记忆锚点：[总共只选 2–4 个：主体身份/姿态、关键空间关系、0–2 个独特细节]
主动删除：[列出不进入重绘的摄影细节，如碎石、草叶、墙面颗粒、湖面碎光、远处小物]
光线与情绪：[光线方向、时段、天气、整体感受]
原图核心色：[选择 2–4 个颜色]
最深可读色：[从原图选一个适合中文文字的深色]
次级强调色：[从原图选一个适合英文/日期的小面积颜色]
主画域结构：[横向刷痕 / 一角式淡彩 / 纵向卷轴 / 宣纸撕边拼接 / 斜向引导]
外包围限制：[横向景观不超过页面 72% 宽 × 46% 高 / 纵向主体不超过 48% 宽 × 62% 高 / 一角式静物不超过 60% 宽 × 52% 高]
越界锚点：[选择 1–3 个适合轻微越出主画域的轮廓]
中式媒介组合：[从毛笔线、淡墨、水彩淡彩、彩铅、木版套色感、宣纸撕边中选择 2–3 种]
必须逐字呈现的文字：[没有则写“无”]
目标比例：[默认 3:4 竖版，或用户指定比例]
```

## 默认生成提示

提示应只保留少量难忘细节，用简化形态重新搭建场景，并保持短而聚焦。填写后删除方括号说明和不适用分支，不要继续追加同义要求。

```text
根据参考照片重新构画一张 [目标比例] 的中式纸本留白记忆画页。只使用当前照片，不混入其他场景。

保留且只保留这些记忆锚点：[2–4 个记忆锚点]。保持人物数量、主体朝向、关键接触关系和大体前后位置；不要追摹原照片的精确轮廓。主动省略：[主动删除项]。

把场景重新拆成 5–12 组可读的大形与疏密层次，再以 [中式媒介组合] 从空白纸面重新落笔：用线条建立轮廓，用有限色块与透明水洗建立体积，用干刷或皴擦提示材质。允许压平透视、合并山峰/树冠/建筑面、简化局部比例和改写边线。除记忆锚点外，非必要细节只保留原照片视觉密度的约四分之一；碎石、草叶、砖缝、木纹、水面碎光和远处小物不得逐项复刻。

插画内部必须彻底失去摄影表面：没有镜头锐度、真实照片颗粒、HDR 微反差、连续写实纹理、景深虚化或边缘检测式轮廓。即使去掉白纸、刷边和题字，剩下的场景也应明显是一幅由手工线条、纸本色块和水洗重新画出的插画，而不是照片套笔触。

以 [主画域结构] 在 [构图位置] 形成紧凑的开放画域。实际有色笔触与明显线条只占整页约 25–32%；插画整体外包围框包含所有越界元素，必须满足 [外包围限制]。四周保留至少 10–15% 安静纸边，顶部通常保留约 28–35% 连续留白；不要让任何笔触、越界线条或题字触碰页面边缘，也不要用稀疏长线把视觉范围拉满整页。不要绘制可见矩形边框。

仅让 [1–3 个越界锚点] 向一到两个方向越出主画域约自身尺度的 5–8%，越界后仍必须处在上述整体外包围框内。其余边缘以淡墨、干刷、宣纸纤维或散点线条收住。

从原照片的 [原图核心色] 提炼纸本色阶，颜色主要停留在主画域和越界锚点。中式气质来自计白当黑、疏密、虚实和书写关系，不添加照片中不存在的灯笼、祥云、宫殿或大印章。

[默认文字分支：在插画附近用 [最深可读色] 的纤细中文手写字逐字呈现“[中文短句]”；再用 [次级强调色] 的更小英文手写字逐字呈现“[英文标签和日期]”。文字与主画域保持页面短边约 3–8% 的呼吸距离，中文和英文组成紧凑注记组，不要分散到页面两端或靠近页边。两组各出现一次，不得改写、重复或增加文字。]
[无文字分支：仅当用户明确要求时，不生成任何文字、数字、Logo、水印或签名。]

禁止照片滤镜、写实修图、照片残片、白底抠图、满版铺色、僵硬相框、商业大标题、扁平矢量、塑料 3D、厚重油画、泛黄旧纸、额外人物和虚构地点。
```

## 重绘强度自检

提交提示前确认：

1. 记忆锚点不超过 4 个，而且写清了哪些细节要主动删除。
2. 提示允许改写非锚点轮廓、合并形体和压平透视，没有要求逐像素或精确复原。
3. 插画内部也被要求重新构形，而不是只要求纸纹、刷边和留白。
4. 若把白纸与题字遮住，主体仍应一眼看出是画，不是照片。
5. 多图处理时，画域位置、宽高比例、边缘形状和文字坐标应跟随各自照片变化，不连续套用同一版式。
6. 分别检查实际着色占比和整体外包围框；不能只靠稀疏笔触满足占比，却让山脊、窗框、水流或刷痕横跨整页。

## 聚焦修正语句

只选择与当前失败现象有关的语句，不要全部追加。

### 主体过大或留白不足

```text
把插画、越界元素与题字作为一个整体等比缩小到当前视觉尺寸的约 70–80%，不要只减少颜色浓度。实际有色笔触与明显线条控制在整页 25–30%；插画外包围按题材收回到 [外包围限制]，四周恢复至少 10–15% 安静纸边，顶部恢复约 28–35% 连续留白。任何山脊、窗框、水流、刷痕或文字都不得触碰页面边缘。
```

### 结果仍像照片滤镜

```text
不要继续修饰现有摄影表面。只保留这些记忆锚点：[锚点列表]，放弃其余原图纹理，从空白纸面重新搭建形体。把山石/树林/草地/墙面/水面分别合并为少量大形与线性笔触，删除碎石、草叶、砖缝、木纹、颗粒、镜头锐度和连续写实明暗。插画内部而不只是外缘，必须明显由铅笔线、纸本色块、透明水洗和干刷重新画成。
```

### 中间画域过于死板

```text
保留主体与空间关系，但取消居中封闭矩形。改用 [横向刷痕 / 一角式淡彩 / 纵向卷轴 / 宣纸撕边拼接 / 斜向引导]；让边缘产生疏密、虚实和不对称变化，并把页边注移到与视觉重心相平衡的一侧。
```

### 所有内容都被困在画域内

```text
只让 [越界锚点 1]、[可选越界锚点 2] 自然越出主画域约自身尺度的 5–8%；保持轮廓完整，并把它们计入 [外包围限制]。其余边缘继续柔和收住，不得用长线或刷痕把越界延伸到页面边缘。
```

### 背景被简化到失去原图关系

```text
只恢复这些记忆锚点及其大体关系：[锚点列表]。保持人物数量、主体朝向、支撑关系以及道路/窗框的主要走向；不要恢复碎石、草叶、墙面颗粒、湖面碎光或其他摄影微细节。
```

### 颜色侵入留白

```text
把所有鲜明颜色收回开放画域与选定的越界锚点；纸面其余区域保持纯净自然白，只允许极轻的纸纤维，不允许彩色雾、渐变或水彩泼洒。
```

### 文字错误

```text
删除所有错误、重复和额外文字。中文只保留并逐字渲染“[中文短句]”，英文只保留并逐字渲染“[英文标签和日期]”；两组各出现一次，不得自动改成无文字版本。
```

### 文字颜色与画面不协调

```text
不要使用固定灰蓝配色。中文改用从原图提取的 [最深可读色]，英文/日期改用从原图提取的 [次级强调色]；两者都要与纸面保持清晰对比，并与画面主色形成同源关系。
```
